# Sprint 11 — детальный план (встроенные стикеры)

Источник: в чате только plaintext `body`, media/S3 нет. Нужен минимальный стикерпак для демо/диплома без загрузки файлов и без новых HTTP-роутов.

Sprint 9 (шифрование) по-прежнему отложен — не смешивать DoD.

## 1) Цель спринта

В PWA можно отправить стикер из **встроенного** пака. Сообщение уходит тем же `POST …/messages`, в `body` — код `sticker:{pack}/{id}`. Оба клиента рисуют картинку из статики приложения, не с сервера.

К концу спринта: кнопка панели стикеров у поля ввода; тап шлёт код; пузырь показывает WebP/PNG; в списке чатов превью «Стикер». TTL и unsend работают как у текста.

## 2) Входные условия

- `POST /api/v1/dialogs/{id}/messages` принимает произвольный plaintext `body`.
- Home preview = `last_message.body_preview` (`BuildPreview`, ≤120 рун).
- Sprint 8: PWA чат; Sprint 10: unsend исходящих.
- Нет object storage, нет поля `type` у сообщения.

## 3) Ключевые задачи

### A. Решения (зафиксировать в чеклисте §1)

| Тема | Решение (Must) |
|------|----------------|
| Хранение | Тот же `messages.body TEXT`. Код, не бинарь |
| Контракт `body` | `sticker:{pack}/{id}`, pack/id = `[a-z0-9_-]+` |
| Пак | Один встроенный `default`, 12–16 штук |
| Откуда файлы | `mobile/public/stickers/default/{id}.png` (+ `NOTICE` с лицензией) |
| HTTP | **Без новых endpoints**. Тот же send / list / WS `message_new` |
| Неизвестный код | Показать плейсхолдер / сам код, не падать |
| Home preview | Клиент: если `body`/`body_preview` — стикер → «Стикер» |
| Push | Без изменений (title = username, body = «Новое сообщение») |
| TTL / unsend | Без изменений |

Источник ассетов (выбрать один, зафиксировать в `NOTICE`): **Fluent Emoji (MIT)** или свой набор. Не копировать паки Telegram/WhatsApp.

### B. Клиент PWA

1. Каталог `STICKERS` в TS: `{ pack, id, src, label }[]`.
2. Кнопка у композера открывает сетку; тап → `sendMessage(dialogId, \`sticker:${pack}/${id}\`)`.
3. Рендер пузыря: `parseStickerBody(body)` → `<img>`, иначе текст как сейчас.
4. Home: `formatPreview(body_preview)` → «Стикер» для кода.
5. Стили: стикер-пузырь без длинного текстового padding; размер ~128–160 px.

Сервер не трогать, кроме случая, если `BuildPreview` сами решат подменить (Should, не Must).

### C. Ассеты

Положить файлы в git (маленькие PNG 256 px). В `NOTICE` — лицензия и атрибуция. Имена файлов = `{id}.png`.

## 4) Что не входит

- Загрузка своих стикеров / фото / S3 / MinIO.
- Новые колонки `type` / `attachment_id`.
- Анимация Lottie, GIF-паки, стикер-маркетологи.
- Серверный каталог / CDN.
- Реакции на сообщение.
- Sprint 9 encryption.
- Правка push body («прислал стикер»).

## 5) Риски

| Риск | Митигация |
|------|-----------|
| Старый клиент видит сырой код | Допустимо: код читаемый; новый PWA рисует картинку |
| Preview на Home = `sticker:default/wave` | Клиентская подмена на «Стикер» |
| Чужой контент / TOS | Только MIT/свои файлы + `NOTICE` |
| `body` слишком длинный / инъекция | Парсер: только точный префикс + charset; иначе текст |
